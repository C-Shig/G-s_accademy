# 課題: じゃんけんアプリ
---
## 1. 作ったもの：　素数判定アプリ
### Site Title: 汝、素数たるや？

## 2. 制作サイトの説明
入力を判定して、素数かどうかなどを返すアプリをつくりました。

## 3. 工夫した点・こだわった点

- HTMLで学んだinputとFlexboxを活かして、なにかjsで遊べないかと考えました。
- 2, 4といった、小さな整数だけでなく、任意の文字列に対して判定できるようにこだわりました。数式、虚数、負の数、小数、分数にも対応しています。
- console.logが読める方はもっと楽しめるよう、見つけた素数が表示される️ようにしました。ぜひ遊んでみて！
- 入力欄にいれたあと、チェックボタンをおしても、Enterを押してもscriptが走るようにしました。

## 4. 難しかった点・次回トライしたいこと

- 素数のときとそうでないときの結果表示が異なるので、
一度大きくしたフォントを戻すには？
表示位置を影響されないようにするには？
というところが難関でした。
- 一度はfunctionが10個になって、あとで整理しました。可読性大事。
- functionの書き方で、アロー関数の場合とそうでない場合がかなり混乱しました。カンペを見ながらでないとまだ正確にかけません。だいぶAIに助けてもらいました。


## 5.感想・備考
- 教育系のWebアプリをつくってみたいと思っているのですが、入力パターンでいくつも分岐させたり、出力パターンもいくつも考えたり、実現には「まず何をつくりたいか」の設計が大切ということが身にしみました。
- 次回以降は、設計前に仕様書を言語化あるいは図示して残せるようにしたいです。
