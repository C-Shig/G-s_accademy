## 課題: メモ帳アプリ

## 1. 作ったもの：　25マス計算アプリ MasuCal

Site Title: MasuCal｜マスカル

## 2. 制作サイトの説明

### 主旨:

小学生の計算練習ドリル代表といえば「100マス計算」
みんなの暗算力を鍛えてきたあの問題たちを、自動で作れるように！した！
**Keyword: いつでも、どこでも、ちょこっと勉強！**

### 2つのhtml

- メインとなる25マス計算の [index.html](https://c-shig.github.io/G-s_accademy/class-04/index.html)
- まちがいリストだけをやり直すためのサイト [wronglist.html](https://c-shig.github.io/G-s_accademy/class-04/index.html)
- おまけ: conlose.logで`logMistakeCount();`を実行すると、まちがいリストに保管されている問題数が表示されます

### 学習ツールとして:

- +,-,✕,÷すべての四則演算に対応
- 縦横見出しの数値は"-100〜100"まで設定OK!
  - 7の段に悩まされる小学2年生にも、負の数に悩まされる中学1年生にも
- 回答サイズを **5x5の25マス** 以外にも、9, 16, 25, 36, 49, 64, 81, 100マスまで対応⭐️
- もちろんスマホ対応
  👉️いつでも、だれでも、レベルに合わせて勉強できる

さらに！

- 答え合わせ機能搭載
- ⭐️⭐️まちがえた問題を保存しておく機能「まちがいリスト」搭載⭐️⭐️
  - まちがいリストは、解いた日、式、誤回答とセットで配列保存。
  - 「まちがいなおし」ボタンで、まちがえた問題だけやりなおしができる！
  - 「まちがいなおし」で正解したら、「まちがいリスト」からの削除もできる
- 印刷できる！
  - 問題のみver, 模範解答とあなたの回答つきver.
  - 印刷して、PDFとして保存しておけば、何回でも練習できる。
  - まちがいリストページ[wronglist.html](https://c-shig.github.io/G-s_accademy/class-04/index.html)の印刷機能は今後搭載予定

## 3. 工夫した点・こだわった点

機能面に絞る。

#### 配列要素をとりいれたい:

- 5個の整数を要素にもつ縦配列・横をつくって、表で計算させる形式にしたら、問題の制作が無限にできるのでは？というのが最初の思い立ち。
- メモ帳のように、配列に要素を次々詰め込んでいく機能は、まちがいリストとして集積しよう、と考えた。

#### 計算の壁、正誤判定の壁

- +, ✕は順序が入れ替わってもOK. -, ÷はどっちが先だかわかるようにしなくては！
- 割り算が難関
  - 割り切れる式だけ表示する？分数OKにする？
  - 縦横配列の数値範囲を負,0,正の数にしたら、0で割るケースを除外しないといけなくなった
  - 4÷2は`2`OK,`4/2`NG,`2.0`NG
  - 2÷4は `1/2`OK, `0.5`OK, `2/4`NG, `0.500`NG
  - 6÷9は `2/3`OK, `6/9`NG, `0.33333`NG

#### 入力箇所の壁

- 最初のセルに入力。普通はEnterを押す。Tabかも。表の横移動。行の最後のセルにいったら次の行の最初のセル。
- 未入力をOKにしたら、最後のセルのあとの入力欄は、最初のみ入力セルに戻るようにしたい
- スマホは最初から数値入力画面だといいな。負の数と分数と小数が有り得るので、`-`と`/`と`.`は入っているキーボードが必要だ

#### 縦横見出し配列の壁

- 1〜10の中から5個が見出しにくる
  - ランダムに要素順を入れ替えるとは？
  - ランダムに要素を入れ替えてから前から5個Pickupするか、5個Pickupしてから要素を入れ替えるか
    👉️使える数値に制約が多いため、次のようにした - 1〜10をランダムに入れ替えた要素数10の配列をつくる - 使ってはいけない要素を除外する - 配列の前から必要数の要素を抜き出し、新しい配列を作る
    Errorメッセージを出すタイミングが難しかった

#### 模範解答配列の壁

- 1元25要素配列にするか、2元配列（5要素x5要素）にするか迷った
- colとrowでカウントできるので1元25要素配列に決定

#### まちがいリスト作成の壁

- 本当に入れるべき要素はなにか？学習面から検討。
  👉️{数値、数値、演算子、誤答、誤回答日時} (順不同記載)とした
- まちがいリストを再掲したい。学習目的からすると25マス計算レイアウトではない。
  👉️やり直し問題を羅列するhtmlを新たに作成。仕事が倍に。
