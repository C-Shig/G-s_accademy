## 課題: じゃんけんアプリ rich ver.
## 1. 作ったもの：　素数コレクション
Site Title: 汝、素数たるや？ | Prime Collection
## 2. 制作サイトの説明
#### rich前:
入力を判定して、素数かどうかなどを返すアプリをつくりました。
#### rich後:
見つけた素数をどんどん画面内に表示。1桁の素数を全部みつけた、などのAchievement機能追加
## 3. 工夫した点・こだわった点
### 機能面
#### rich前:
- 2, 4といった、小さな整数だけでなく、任意の文字列に対して判定できるようにこだわりました。数式、虚数、負の数、小数、分数にも対応しています。
- console.logが読める方はもっと楽しめるよう、見つけた素数が表示される️ようにしました。ぜひ遊んでみて！
- 入力欄にいれたあと、チェックボタンをおしても、Enterを押してもscriptが走るようにしました。
#### rich後:
- 見つけた素数が画面内に常時されるようにしました。2,3,5,7をみつけると、すべてがMy Prime Collectionに表示される
- 発見された個数を表示
- n桁の素数、双子素数、メルセンヌ素数など、いろんな素数コレクションを想定してAchievement基準を策定。達成すると、Achievementにバッジが表示されるようにしました。バッジは絵文字をcss gridで囲むようにつくりました。
